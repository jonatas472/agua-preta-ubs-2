# 🏥 Água Preta UBS

Aplicativo desenvolvido pelo **Grupo Apollo**, do 3º ano do Ensino Médio, para facilitar o acesso dos moradores de Água Preta aos serviços da UBS.

## 🎯 Objetivo

Permitir que os usuários:

- 📅 Realizem agendamentos de consultas;
- 🏥 Consultem serviços e horários da UBS;
- 💉 Acessem informações sobre vacinas;
- 📋 Visualizem seus próximos agendamentos.

## 🛠️ Tecnologias

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- Room Database
- Coroutines / Flow
