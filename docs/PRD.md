# PRD - Água Preta UBS

**Versão:** 1.0
**Data:** 06/10/2026

## 1. Visão Geral
O aplicativo Água Preta UBS visa facilitar o agendamento de consultas e prover informações confiáveis sobre vacinas para a comunidade local.

## 2. Funcionalidades (MVP)
- **F1: Agendamento Local:** Salvar dados de consulta no dispositivo (Room).
- **F2: Painel de Serviços:** Listagem de horários e serviços da UBS.
- **F3: Mural Verdade ou Mito:** Seção informativa sobre vacinas.
- **F4: Visualização de Agendamentos:** Lista de compromissos salvos.

## 3. Requisitos Técnicos
- **Linguagem:** Kotlin
- **Interface:** Jetpack Compose
- **Banco de Dados:** Room
- **Navegação:** Navigation Compose

## 4. Design
- **Cor Principal:** #668D3D (Verde Apollo)
- **Estilo:** Acessível para idosos, botões grandes e ilustrados.
